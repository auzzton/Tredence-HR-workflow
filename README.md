# HR Workflow Designer

Visual, drag-and-drop workflow designer for HR processes (onboarding, leave approval, document verification). Built as the case study for the **Tredence Studio — Full Stack Engineering Intern (AI Agentic Platforms)** application.

> **Status:** in progress — scaffold complete, canvas/nodes/forms landing incrementally. Polished README at the end.

## Quick start

```bash
npm install
npm run dev
```

Then open the printed local URL. `npm run build` produces a static `dist/` deployable to Vercel.

## Tech

Vite · React 19 · TypeScript (strict) · @xyflow/react v12 · Zustand · Tailwind v4 (via `@tailwindcss/vite`) · react-hook-form · zod · MSW · lucide-react · Vitest.

Full architecture notes, design decisions, and feature checklist land in this README once the build is done.
